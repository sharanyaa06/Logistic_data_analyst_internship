# Week 3 – Advanced Data Analysis and Visualization in Logistics

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) and visualization of logistics data using Python.

The objective is to analyze a hypothetical logistics dataset and identify meaningful patterns related to shipment volume, delivery time, transportation costs, distance, and delivery performance.

Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn are used to perform the analysis and create visualizations.

---

## 🎯 Objectives

The main objectives of this project are:

* Create a hypothetical logistics dataset.
* Perform Exploratory Data Analysis.
* Calculate descriptive statistics and central tendencies.
* Analyze logistics data distributions.
* Study relationships between numerical variables.
* Create meaningful visualizations.
* Identify logistics performance patterns.
* Identify potential cost drivers and bottlenecks.
* Provide recommendations based on analytical findings.

---

## 📊 Dataset

A hypothetical logistics dataset is generated using Python.

The dataset contains 100 shipment records and includes:

| Variable            | Description                           |
| ------------------- | ------------------------------------- |
| Shipment_ID         | Unique shipment identification number |
| Month               | Month of shipment                     |
| Region              | Shipment region                       |
| Transport_Mode      | Mode of transportation                |
| Shipment_Volume     | Number of units shipped               |
| Delivery_Time       | Delivery duration in days             |
| Transportation_Cost | Transportation cost                   |
| Distance            | Distance travelled in kilometres      |
| Delivery_Status     | On Time or Late                       |

The dataset is generated programmatically so that the analysis is reproducible.

## 📈 Exploratory Data Analysis

The following analysis is performed:

### Descriptive Statistics

The project calculates:

* Mean
* Median
* Minimum
* Maximum
* Standard deviation

These measures help understand the general characteristics of logistics operations.

### Distribution Analysis

A histogram is used to analyze the distribution of delivery times.

### Transportation Cost Analysis

Average transportation costs are compared across different transportation modes.

### Shipment Volume Analysis

Monthly shipment volumes are visualized using a line chart to identify changes in shipment activity.

### Relationship Analysis

A scatter plot is used to study the relationship between distance and delivery time.

### Delivery Performance

Delivery status is analyzed to compare on-time and late shipments.

### Outlier Analysis

A box plot is used to identify the spread and potential extreme values in transportation costs.

### Correlation Analysis

A correlation matrix and heatmap are used to analyze relationships between:

* Shipment Volume
* Delivery Time
* Transportation Cost
* Distance
